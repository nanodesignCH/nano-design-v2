# nano design

Website von [nano design](https://nano-design.ch) – web & print design aus Orpund.

Next.js 16 · React 19 · Tailwind CSS v4 · Vercel

## Entwicklung

```bash
npm install
npm run dev
```

`npm run check` führt Lint, Typecheck und Build aus. Für das Kontaktformular `.env.example` nach `.env.local` kopieren und `RESEND_API_KEY` setzen.
